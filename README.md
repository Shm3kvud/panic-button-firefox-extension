# Panic Button – Tab Hider

Небольшое расширение для Firefox — аналог Panic Button из Opera GX.

По нажатию F12 все вкладки текущего окна скрываются, а вместо них открывается
главная страница Google. Повторное нажатие возвращает всё как было: те же
вкладки с тем же состоянием (история внутри страницы, закреплённые вкладки,
ранее активная вкладка). Проигрывающее видео и аудио при этом ставится на паузу,
а после возврата продолжается с того же места. Если медиафайл уже был
остановлен — он останется остановленным.

Расширение ничего не собирает и никуда не отправляет: работает полностью локально.

## Установка

Установить расширение можно из магазина дополнений Firefox -> https://addons.mozilla.org/ru/firefox/addon/panic-button-tab-hider/

## Запуск из исходников (для разработки и тестирования)

1. Откройте в Firefox адрес `about:debugging#/runtime/this-firefox`
2. Нажмите «Загрузить временное дополнение…»
3. Выберите файл `manifest.json` из этой папки

Временная установка действует до перезапуска браузера.

## Горячая клавиша

По умолчанию используется F12, которая в Firefox занята DevTools.
Если хоткей не срабатывает — переназначьте его:
`about:addons → шестерёнка → Управление сочетаниями клавиш расширений`.
Также доступна кнопка расширения на панели инструментов.

## Ограничения

- Работает только в Firefox (в Chromium-браузерах нет API скрытия вкладок)
- При первом скрытии вкладок Firefox покажет своё однократное уведомление —
  это поведение браузера, его отключить нельзя
